(Archivos reader/reader.h y reader/reader.c)

Dispone de dos funciones de lectura, una para el bloque principal (el propio archivo .kut) y otro para los demás bloques (bloques interiores).

Lector del bloque principal

Lee un archivo .kut y retorna el módulo correspondiente.

Esta función necesita que se le pase un un objeto de la clase lector de caracteres.

Inicializa los campos imports, exports y heap0 del módulo.

Además inicializa un array tps que contendrá los símbolos con los que se accede a los módulos de los que depende el módulo que se está leyendo. La inicialización se hace añadiendo los símbolos correspondientes a los módulos-base de kut.

A continuación se van leyendo las sucesivas instrucciones y añadiéndolas en un array.

Por último se invoca el constructor de la clase module y se retorna el objeto creado.

Lectura de las sucesivas instrucciones

Se realiza dentro de un bucle que se desarrolla según el siguiete esquema:

Se lee la siguiente instrucción y se obtiene la StatCode (st) correspondinente.

    Si st es de tipo break

    Se finaliza el bloque.

    Si st es de tipo import

    - Se comprueba que el simbolo identificador del módulo importado no ha sido previamente importado o incluido en el Heap0 del módulo.
    - Acto seguido se comprueba que el archivo que se importa es accesible para su lectura.
    - Por último se añaden los datos correspodientes de los objecto imports, heap0 y tps.

    Si st es de tipo indexed

    - Primero se determina si los símbolos del indexed se van a exportar.
    - A continuación se asigna una función de tipo \p1, p2 ... -> return p1, p2 ... al primer símbolo del indexed (donde p1, p2 ... son los símbolo del indexed que sigen al primero -- eventualmente puede no haber ninguno).
    - Hecho esto, se asignan los símbolos p1, p2, ... a los enteros 0, 1, ...
    - Todas las asignaciones, después de comprobar que los símbolos no están ya registrados en los imports ni en el heap0, se añaden a los exports, si procede, al heap0 y al array de instrucciones.

    Si st es de tipo arr_multi o dic_multi

    Con el fin de actualizar los exports y el heap0:

    - Primero se determina si los símbolos de la instrucción se van a exportar.
    - A continuación se extraen los valores new_sym, syms y exp del constructor de la instrucción.
    - Con new_sym se crea una instrucción interna que le asigna: En el caso de arr_multi, un array de enteros de 0, inclusive, al número de elementos de syms, exclusive. En el caso de dic_multi, un diccionario que asocia los simbolos de syms a expresiones de cadena con el mismo símbolo (p.e. a -> "a").
    - Hecho esto, se crean instrucciones de tipo sym = exp[new_sym[i]] en el caso de arr_multi, o sym = exp[new_sym[symbol]] en el de dic_multi. Una para cada valor de syms que no sea una expresión vacía.
    - Todas las asignaciones, después de comprobar que los símbolos no están ya registrados en los imports ni en el heap0, se añaden a los exports, si procede, y al heap0.

    NOTA: Estas asignaciones NO se registran el array de instrucciones. Lo que añade a tal array es la propia instrucción de tipo arr_multi o dic_multi.

    Si st es de tipo asign

    - Con el fin de actualizar los exports y el heap0 se comprueva que el símbolo de la asignación no está ya registrado en los imports ni en el heap0, y se añade a los exports, si se determina que es una instrucción para exportar, y al heap0.
    - Hecho esto se añade al array de instrucciones.

    Cualquier otra st

    Se añade al array de instrucciones.

Una vez finalizada la inserción de instrucciones en su array:

  1. Se eliminan del mismo las instrucciones de tipo export, que ya no son necesarias.

  2. Se crea y retorna el módulo correspondiente con los datos de los imports, exports, heap0 y array de instrucciones.

Lector de bloque no principal

Lee un bloque interno (situado entre los tokens { y }).

Esta función necesita que se le pase un array tps que contendrá los símbolos con los que se accede a los módulos de los que depende el código que llama a la función y un un objeto de la clase lector de caracteres.

Prepara un nuevo tps para añadir los símbolos de la función y lee las sucesivas instrucciones in un array.

Una vez finalizada la lectura se retorna el array,

Lectura de las sucesivas instrucciones

Se realiza dentro de un bucle que se desarrolla según el siguiete esquema:

Se lee la siguiente instrucción y se obtiene la StatCode (st) correspondinente.

  • Si st es de tipo end o de tipo import, se lanza una excepción.

  • Si st es de tipo export, se descarta.

  • Si st es de tipo 'cierre de bloque' (block_close), se descarta y se finaliza la lectura del bloque.

  • En otro caso st se anade la array de instrucciones.

Lector de instrucción

(Archivos reader/st_reader.h y reader/st_reader.c)

El código sólo exporta la función st_reader_read, que lee una instrucción.

Función st_reader_read.

Esta función necesita que se le pase un array tps que contendrá los símbolos con los que se accede a los módulos de los que depende el código que llama a la función y un un objeto de la clase lector de caracteres.

Retorna una StatCode (st) conforme el siguiente algoritmo:

Lee el siguiente token (tk) .

Si no hay más tokens que leer, devuelve una st de tipo end.

En otro caso:

    Si tk es de tipo TOKEN_LINE_COMMENT.

    Si la línea comienza con /// retorna una st de tipo export.
    En otro caso retorna el resultado de llamar recursivamente la función st_reader_read.

    Si tk es de tipo TOKEN_COMMENT.

    Retorna el resultado de llamar recursivamente la función st_reader_read.

    Si tk es el operador 'dos puntos' (:).

    Se leen sucesivamente dos tokens: El primero corresponde a un símbolo o a a otro operador 'dos puntos'. El segundo debe ser un simbolo (en otro caso se lanza un excepción).
    Acto seguido se actualiza el array tps asociando el símbolo del segundo tocken con el valor del índice del símbolo del primer token, o con '-1', si dicho tocken es el operador 'dos puntos'.
    Hecho esto se lee una instrucción Stat(st) con la función read, pasandole el segundo token leído.
    - Si st es una asignación distinta de una asignación a símbolo (p.ej. una asignación a array) se lanza un excepción.
    - Si st no es una asignación (ya sea normal o múltiple) también se lanza una excepción.
    - En otro caso se retorna una StatCode con st.

    Si tk es el operador 'coma' (,).

    Se llama a la función read_multi y se retorna una StatCode con la Stat obtenida.

    En otro caso.

    Se llama a la función read pasándole tk y se retorna una StatCode con la Stat obtenida.

Función read

Esta función necesita que se le pase un array tps que contendrá los símbolos con los que se accede a los módulos de los que depende el código que llama a la función, un un objeto de la clase lector de caracteres y el último token leído (tk).

Retorna una instrucción Stat.

    Si tk es de tipo TOKEN_SYMBOL.

    Llama a la función read_symbol, pasándole el índice del símbolo de tk, y retorna el resultado.

    Si tk es el operador 'llave abierta' ({).

    Retorna una instrucción de tipo 'bloque' con el array retornado por la función reader_read_block.

    Si tk es el operador 'llave cerrada' (}).

    Retorna una instrucción de tipo 'bloque cerrado'.

    En otro caso.

    Lanza un excepción.

función read_symbol

Esta función necesita que se le pase un array tps que contendrá los símbolos con los que se accede a los módulos de los que depende el código que llama a la función, un un objeto de la clase lector de caracteres y el índice del símbolo que se acaba de leer (sym).

    Si sym es BREAK.

    Se lee el token ';' y se retorna una instrucción 'break'.

    Si sym es CONTINUE.

    Se lee el token ';' y se retorna una instrucción 'continue'.

    Si sym es TRACE.

    Se lee el siguiente token si es 'dos puntos' (en este caso 'trace' mostrará la expresión forma completa) y a continuación se lee una expresión y el token ';'.
    Se retorna una instrucción 'trace' con la expresión y el indicador de 'mostrar completamente'.

    Si sym es RETURN.

    Se lee el siguiente token.
    - Si es ';' se retorna una instrucción 'return' que retorna la expresión vacía (empty).
    - En otro caso se lee una expresión, el token ';' y se retorna una instrucción 'return' con la expresión leida.

    Si sym es IMPORT.

    Se lee un token de tipo 'string' (path) y se comprueba que es correcto (no se admiten paths que empiecen o terminen con '/', que contengan puntos ('.') o que sean 'strings' vacías.
    A continuación se lee el siguiente token:
    - Si es ';' se establece como identificador la base de path.
    - Si es ':' se lee un símbolo y el token ';', stableciéndose como identificador el símbolo leído.
    - En otro caso se lanza un excepción.

    Si sym es TRY.

    Lee un bloque TRY-CATCH-FINALLY con el siguiente algoritmo:
    - Lee una StatCode con la función st_in_read (st1).
    - Lee el token 'catch' (si no se encuentra se lanza una exceptión).
    - Lee el símbolo del bloque CATCH, entre paréntesis (si no se encuentra se lanza una excepción).
    - Lee una StatCode con la función st_in_read (st2).
    - Se intenta leer el token 'finally'. Si se encuentra se lee una StatCode con la función st_in_read en la opción (st3). En otro caso la opción (st3) queda vacía.
    - Por último se retorna una instrucción de tipo 'try' con st1, st2, st3 y la símbolo del bloque CATCH.

    Si sym es CATCH.

    Se lanza un excepción indicando que CATCH está fuera un bloque TRY.

    Si sym es FINALLY.

    Se lanza un excepción indicando que FINALLY está fuera un bloque TRY.

    Si sym es WHILE.

    Lee
    - Un par de paréntesis vacío seguido por una StatCode, leida con la función st_in_read, retornando un instrucción 'while'.
    o
    - Una expresión entre paréntesis, usanado la función lector de expresión, seguida por una StatCode, leida con la función st_in_read, retornando un instrucción 'while'.

    Si sym es IF.

    Lee una expresión entre paréntesis, unsando la función lector de expresión, seguida por una StatCode, leida con la función st_in_read (st1).
    A continuación se intenta leer el token 'else'. Si se encuentra se lee una StatCode con la función st_in_read en la opción st2. En otro caso la opción st2 queda vacía.
    Por último se retorna una instrucción 'if' con la expresión leida, la instrucción st1 y la opción st2.

    Si sym es ELSE.

    Se lanza un excepción indicando que ELSE está fuera un bloque IF.

    Si sym es FOR.

    Se lee un token 'paréntesis ('. A continuación:

    - Si el siguiente token es 'dos puntos' (:)
      > Se leen dos símbolos (de modulo y 'variable').
      > Se lee el token igual (=).
      > Se lee una expresión con la función lector de expresión.
      > Se lee un token 'paréntesis )'.
      > Se lee una StatCode, leida con la función st_in_read.
      > Se retorna una instrucción 'for' de tipo for (:md v = contenedor).

    - En otro caso el siguiente token debe ser un símbolo (v1)

    Se inicializa v2=-1 y se lee un nuevo token (tk).

    - Si tk es una coma (,)
      > Si el siguiente token es 'dos puntos' (:)
        > Se leen dos símbolos (de modulo y 'variable').
        > Se lee el token igual (=).
        > Se lee una expresión con la función lector de expresión.
        > Se lee un token 'paréntesis )'.
        > Se lee una StatCode, leida con la función st_in_read.
        > Se retorna una instrucción 'for' de tipo for (i, :md v = contenedor).
      > En otro caso el siguiente token debe ser un símbolo distinto de v1, que se asigna a v2.

    - Si no es una coma se sigue con v2 igual a -1.

    Se lee el token igual (=).
    Se lee una expresión con la función lector de expresión (ex1).

    - Si el siguiente token es 'dos puntos' (:) [for de tipo 'range']
      > Si v2 es distinto de -1 se lanza una excepción.
      > Se lee una expresión con la función lector de expresión (ex2).
      > Se lee un nuevo token.
        > Si el token es 'dos puntos' (:) se lee en ex3 una expresión con la función lector de expresión.
        > En otro caso ex3=NULL.
      > Se lee un token 'paréntesis )'.
      > Se lee una StatCode, leida con la función st_in_read.
      > Se retorna:
        > Si ex3 es NULL, una instrucción 'for' de tipo for (i = start:end).
        > En otro caso, una instrucción 'for' de tipo for (i = start:end:step).
    - Si no es 'dos puntos' (:) ni 'paréntesis )', se lanza una excepción.

    Se lee el token 'paréntesis )'.
    Se lee una StatCode, leida con la función st_in_read.
    Se retorna:
      > Si v2 es -1, una instrucción 'for' de tipo for (v = contenedor).
      > En otro caso, una instrucción 'for' de tipo for (i, v = contenedor).

    Si sym es SWITCH.

    Se lee una expresión entre paréntesis, unsando la función lector de expresión.
    A continuación comprueba que sigue un token 'llave{'.
    Se establece la variable with_default a FALSE.
    Después se leen los distintos casos en un array, hasta que el siguiente token sea 'llave}' siguiendo el siguiente algoritmo:
    - Se lee un array de condiciones de la siguiente manera:
      > Se lee una expresión con el lector de expresión y se añade al array de condiciones.
        > Si la expresion es el símbolo 'default' se establece with_default a TRUE.
        > En otro caso se establece un bucle que lee el token 'coma' (,)
           seguido de una expresion (leida con el lector de expresión), hasta que la 'coma' no aparezca.
            - Si la expresión es el símbolo 'default' se lanza una excepción.
            - Cada expresión así leida se añade al array de condiciones.
    - Se lee el token 'dos puntos' (:)
    - Se lee una StatCode, leida con la función st_in_read.
    - Se añade una tupla con el array de condiciones y la instrucción al array de condiciones.
    - Si with_default es TRUE y el siguiente token no es 'llave}', se lanza una excepción.
    Se lee el token 'llave}' y se retorna una instrucción de tipo 'switch' con el array de casos.

    Si sym es un símbolo diferente de los anteriores.

    Se lee una expresión exp con la función lector de expresión extendida, pasando sym como argumento.
    A continuación se lee el siguiente token (tk), resultando:

    - Si tk es ';'
      > Si exp es 'pr' (función) se retorna una instrucción de tipo 'func'.
      > En otro caso se lanza una excepción.

    - Si tk es 'dos puntos' (:)
      > Si exp no es de tipo símbolo se lanza una excepción.
      > Se leen uno o más tokens de tipo símbolo, separados por comas (,)
         y terminados en ';'.
      > Se crea un array con exp mas los símbolo leídos, pasados a expresiones.
      > Se retorna una instrucción de tipo "indexed" creada con el array.

    - Si tk es 'coma' (,)
      > Si exp no es de tipo símbolo se lanza una excepción.
      > Se lee una asignación múltiple con la función read_multi y se retorna la instrucción.

    - Si tk es de tipo asignación
      > Si tk es igual (=) y exp no es de tipo 'símbolo', 'punto' or 'subíndice', se lanza una excepción.
      > Si tk es distinta de igual (=) y exp no es una tipo 'punto' or 'subíndice', se lanza una excepción.
      > Se lee una nueva expresión con el lector de expresión) (exp2).
      > Si tk es el símbolo "=" y types_in_block(tps, exp_get_sym(exp)) es FALSE (ver Tipos),
         se añade a tps el simbolo de exp asociado a
           str si exp2 es una cadena literal,
           arr si exp2 es un array literal,
           dic si exp2 es un diccionario literal.
      > Se lee el token ';'.
      > Se retorna una instrucción de asignación con el siguinte código.
           return token_is_equals(tk) ? stat_assign(exp, exp2)
             : !strcmp(tk->value, "+=") ? stat_add_as(exp, exp2)
             : !strcmp(tk->value, "-=") ? stat_sub_as(exp, exp2)
             : !strcmp(tk->value, "*=") ? stat_mul_as(exp, exp2)
             : !strcmp(tk->value, "/=") ? stat_div_as(exp, exp2)
             : !strcmp(tk->value, "%=") ? stat_mod_as(exp, exp2)
             : !strcmp(tk->value, "&=") ? stat_and_as(exp, exp2)
             : stat_or_as(exp, exp2)
          ;

    - Si tk es distinto de ';', de 'dos puntos' (:), de coma (,) y no es de tipo asignación, se lanza una excepción.

función read_multi

Esta función lee una asignación múltiple. Para ello construye un array de expresiones tipo símbolo, que puede tener elementos con expresiones vacías (exp_empy).

Inicialmente se comprueba si el símbolo (índice) enviado como parámetro es igual a '-1', en tal caso el array de expresiones de símbolo se inicializa con una expresión vacía. En otro caso dicho array se inicializa vacío.

A continuación se van leyendo sucesivos símbolos separados por comas y eventualmente precedidos por una declación de módulo (:modulo). En en caso de ser precedidos por dicha declaración, se actualiza el archivo tps.

La lectura finaliza al encontar:

  • Un signo igual seguido de (;):
    Se retorna una instrucción de tipo array_multi que contiene una enumeración numérica.

  • Un signo igual seguido de una expresión y (;):
    Se retorna una instrucción de tipo array_multi que contiene una asignación múltiple de 'array'.

  • Un signo 'dos puntos' (:) seguido de (;):
    Se retorna una instrucción de tipo dic_multi que contiene una enumeración de 'strings'.

  • Un signo 'dos puntos' (:) seguido de una expresión y (;):
    Se retorna una instrucción de tipo dic_multi que contiene una asignación múltiple de 'dictionary'.

Si después de leer un símbolo no se encuentra (,), (:) ni (=) se lanza una excepción.

función st_in_read

Lee una instrucción que completa bloques 'try', 'if', 'while', 'for' y 'switch'.

Si dicha instrucción es un cierre de bloque (}), un 'import' o un final de archivo, se lanza una excepción.

En otro caso se devuelve la instrucción leida.

Lector de expresión

(Archivos reader/ex_reader.h y reader/ex_reader.c)

Lee una expresión con las funciones:

    ex_reader_read1

    Que lee una expresión simple (sin operadores ni extensión.

    ex_reader_read

    Que lee una expresión completa.

ex_reader_read1

Lee y retorna una expresión buscando sucesivamente:

  • Expresión 'paréntesis' (PAR).

  • Expressión 'unaria' (NOT, MINUS).

  • Expresión 'corchete' (ARR, RANGE).

  • Expresión 'llave' (DIC).

  • Expresión 'función' (FUN). Se llama a las funciones:
    - st_reader_read para leer el código.
    - function_new para crear la función.

  • Comentario. Lo salta y vuelve a llamar a ex_reader_read1.

  • Sucesivamente BOOL, INT, FLOAT, STRING, SYMBOL Y SWITCH.

Si se ha encontrado una expresión, se retorna. En otro caso se lanza una excepción.

ex_reader_read

Se utliza la función add_expressions para crear un array de 'expresiones-operador' ([Exp, Token, Exp, Token ..., Exp]). Esta función recibe un array vacío y funciona como sigue:

Lee una expresión simple con ex_reader_read1 y la extiende usando la función pt_sq_pr_reader_read.

La añade al array de 'expresiones-operador'.

  • Si a continuación hay un operador binario se añade también y se vuelve a llamar a add_expressions.

  • En otro caso se retorna el array.

El array se va reduciendo llamando sucesivamente a las funciones solve_level1 (* / %), solve_level2 (+ -), solve_level3 (== != > >= < <=) y solve_level4 (& |), para generar una expresión que incluya todos los operador por su nivel de precedencia. Esta expresión queda en el índice 0 de dicho array.

Por último, con la expresión resultante tras ordenar los operadores binarios, se procesa el operador ternario (?), si aparece.

La expresión resultante se retorna.

Lector de expresión extendida

(Archivos reader/pt_sq_pr_reader.h y reader/pt_sq_pr_reader.c)

La única función de este archivo (pt_sq_pr_reader_read) completa una expresión simple de tipo 'simbolo' con operadores de máxima precedencia. Se procesa sequencialente:

  • Expresión 'punto' (PT).

  • Expresión 'corchete' abreviada con (!) (SQ con valor [0]).

  • Expresión 'cochete' noraml (SQ SLICE).

  • Expresión 'paréntesis' (PR).

Si se encuentra una de tales expresiones, se vuelve a llamar a pt_sq_pr_reader_read. En otro caso se devuelve la expresión que se recibe como parámetro.
