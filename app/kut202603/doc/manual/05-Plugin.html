Description.

Kut allows new features written in C. This is specially usefull when it is necessary run parts of program faster than it is possible with normal code.

Kut have functions to do that in the built-in module plugin. The are:

    open (\path ->)

    Load pluging functions and returns an object of type <plugin>.
  path: Path of dynamic library (.so)
\s -> <plugin>

    close (\pl ->)

    Close plug-in.
  pl: Plug-in open with 'open'.
\<plugin> -> ()

    exec (\pl, fn, Pars ->)

    Execute the plug-in function called 'fn' and returns its value, which can
be of type EXP_EMTPY, EXP_BOOL, EXP_INT, EXP_FLOAT, EXP_STRING or
EXP_OBJECT.
  pl: Plug-in open with 'open'.
  fn: C name of function embedded in the .so library.
  Pars: Parameters to pass to 'fn'. Its type must be EXP_BOOL, EXP_INT,
        EXP_FLOAT, EXP_STRING or EXP_OBJECT.
\<plugin>, s, [*.] -> *

Let's see an example of preparing and using a plug-in.

The plug-in will have tree main functions:

  • echo: Shows in console a text.

  • sum: Sums two integers and returns its result.

  • mul: Multiplies two integers and returns its result.

To construct that we follow tree steps:

  • Make a kut library.

  • Make a C program to construct a .so library.

  • Use the plug-in.

Make a kut library.

  1. Create a new directory (mkdir 'libplug').

  2. Inside it create a .kut module with the interface (skeleton.kut).

Content of skeleton.kut:

// s path = file.cat([file.parent(mFILE), "skeleton.so"]); // <plugin> sk = plugin.open(path); /// \ -> () close = \sk -> plugin.close(sk);; /// \s -> () echo = \s -> plugin.exec(sk, "skeleton_echo", [s]);; /// \i, i -> i sum = \n1, n2 -> return plugin.exec(sk, "skeleton_sum", [n1, n2]);; /// \i, i -> i mul = \n1, n2 -> return plugin.exec(sk, "skeleton_mul", [n1, n2]);;

NOTE 1: When the module is imported automatically the .so library is loaded. It must be in then libplug directory.

NOTE 2: Function close is added to allow to free resources when the module is not necessary any more. After close the module remains disabled.

Make the .so library.

  1. Create C program directories with the next structure: 

      cskeleton
  ├ bin
  ├ include
  │ └ sub
  ├ lib
  ├ obj
  │ └ sub
  └ src
    └ sub

  2. In cskeleton/lib copy the library libkut.a: 

      cskeleton/lib
  └ libkut
    ├ include
    │ └ ... .h files
    └ libkut.a

  3. Copy exp.h in cskeleton/include and exp.c in cskeleton/src.

    See code here.

  4. Create C files.

    cskeleton/include/skeleton.h
    cskeleton/include/sub/mul.h
    cskeleton/src/skeleton.c
    cskeleton/src/sub/mul.c

    See code here.

  5. In cskeleton copy Makefile

    See code here.

  6. From cskeleton run make.

  7. Copy skeleton/bin/skeleton.so in libplug/skeleton.so.

Use the plug-in

  1. Create a directory (mkdir 'test').

  2. Copy o link libplug as test/libplug.

  3. Create and run test/main.kut

Code of test/main.kut

import "libplug/skeleton"; { skeleton.echo("Test ok."); sys.test(skeleton.sum(3, 5), 8); sys.test(skeleton.mul(3, 5), 15); }
